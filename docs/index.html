門市進貨查詢

查 EPB 調撥入庫（APL 主機）。同事的門市電腦已裝 800AB/EPB，不需另外裝任何大型軟體。

⬇ 下載啟動檔

下載後雙擊即可，會自動安裝到桌面並自動更新。

使用步驟

  1. 連上公司 VPN（需能連到 192.168.1.177）
  2. 雙擊剛下載的 啟動門市進貨查詢.command
    首次會被 macOS 攔下：在檔案上按右鍵 →「打開」→ 再按「打開」一次即可（之後從桌面雙擊不會再跳）。
  3. 稍候會自動開啟瀏覽器 http://127.0.0.1:8781/，選我方倉與日期即可查詢、下載 Excel。

關閉黑色終端機視窗即停止。下次直接雙擊桌面資料夾「門市進貨查詢-app」裡的同名檔，會自動更新到最新版。

進階：用指令安裝（備援）

若雙擊方式不順，可開「終端機」貼上這行：

curl -fsSL https://raw.githubusercontent.com/samwang38/store-in/main/install.sh | bash
固定查詢條件（比照系統匯出，無法在畫面更改）：調撥入庫 INVTRNIN｜來源倉 SA099 總公司倉｜APL 主機（類別1 含 1003/1001、類別2 = 2001、類別3 = 3001）。可調整的只有「我方倉」與「日期」。
